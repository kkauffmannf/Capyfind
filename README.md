# 🦫 Capyfind

**Capyfind** is an open-source, AI-powered "find-the-capybara" game — like *Where's Waldo*, but with capybaras hidden in AI-generated scenes.

This project's main goal is educational: to learn how to build **multi-agent systems** with **LangChain**, **LangGraph**, and **MCP**, using free tools like **Groq** and **Stability AI**.

## 🎯 Project Status
Starting fresh! This repo has been cleaned and is ready for a new implementation.

## 🧩 Planned Tech Stack

| Image Generation | HuggingFace / Stability AI |
| Automation | MCP (Model Context Protocol) |
| Version Control | Git + GitHub |
